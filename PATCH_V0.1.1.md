# V0.1.1 Instant Weapons
- Core rule fixed: touch = immediate HIT/MISS judgment.
- No projectile travel or drag mechanics.
- Weapon progression: 권총(1-3) → 장총(4-6) → 투척(7-9) → 젓가락(10).
- Weapon animation is post-touch visual feedback only and never delays hit detection.
- Existing V0.2.7 movement difficulty, numbered order, timer, and 3-MISS rule are preserved.
